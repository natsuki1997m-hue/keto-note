# ケトン食ノート

ケトン食療法の記録用アプリです。食べたものとグラムを入れると、脂質・糖質・たんぱく質・カロリー・ケトン比（脂質 ÷（たんぱく質＋糖質））を計算します。

- 朝食・昼食・夕食・間食ごとに記録
- よく作る料理を「マイフード」に登録して、ボタンひとつで追加
- 1日の目標は任意（空のままでも使えます）
- 記録は使っている端末のブラウザに保存されます（「せってい」にバックアップあり）

## データの出典

食品の数値は、文部科学省「日本食品標準成分表2020年版（八訂）」から引用しています（可食部100gあたり）。糖質は「利用可能炭水化物（質量計）」です。この値がない食品は、炭水化物から食物繊維と糖アルコールを引いて求めています。

食事の内容は、主治医・管理栄養士の指示を優先してください。
